# 🧮 Calculadora JS

Uma calculadora simples desenvolvida com **HTML, CSS e JavaScript**, criada para **fins educacionais**, permitindo realizar operações matemáticas básicas de forma rápida e intuitiva.

---

## 🚀 Funcionalidades

* Inserção de **dois números**
* Operações disponíveis:

  * ➕ Soma
  * ➖ Subtração
  * ✖️ Multiplicação
  * ➗ Divisão
* Exibição imediata do **resultado**
* ✅ Validação de campos:

  * Caso apenas um número seja informado, o sistema exibe a mensagem
    **"Preencha os dois campos!"**
* Botão **"Limpar"** para resetar os campos e realizar novos cálculos

---

## 🧠 Como funciona

1. O usuário digita o **primeiro número**
2. Insere o **segundo número**
3. Escolhe a operação desejada clicando em um dos botões
4. O sistema valida os campos antes de calcular
5. O resultado é exibido na tela (ou uma mensagem de aviso)
6. O usuário pode clicar em **"Limpar"** para iniciar um novo cálculo

---

## 🛠️ Tecnologias utilizadas

* **HTML5** → estrutura da aplicação
* **CSS3** → estilização da interface
* **JavaScript** → lógica e interatividade
